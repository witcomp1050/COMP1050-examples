# Examples for this lecture

`SlideNN.java` is the complete program behind slide NN. Friendly aliases: none.
JavaFX examples (classes that extend Application or use @FXML) run inside the course JavaFX starter or a JavaFX Classroom 50 template with javafx:run; they were compiled against JavaFX 25 here. The lambda examples are plain console programs.

Each file is self-contained: compile and run one at a time (`javac Slide07.java` then `java Slide07`), or make a new
Eclipse Java project per example. Files whose class ends in `Test` need JUnit 6; open those inside a course Classroom
project instead of compiling them alone.

Every runnable program was compiled with JDK 25 (`--release 25`) and executed; its output matched the slide.
Test-class examples were compiled against the JUnit 6 API.
